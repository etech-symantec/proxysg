    DASH Dashboard

    확인할 항목을 선택하세요

    왼쪽 화면의 항목을 누르면 Broadcom SGOS 7.3 공식 문서의 로그 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    상단 메뉴부터 시스템 사용량, 사용자 수, 트래픽 현황까지 차례로 살펴볼 수 있습니다.

    운영 예시

    CPU 사용률이 평소보다 높다면 시간 범위를 넓혀 일시적인 증가인지 지속적인 과부하인지 먼저 구분합니다.

    메뉴 글자 위에 마우스를 올리면 클릭 영역이 표시됩니다. 아래로 스크롤해 모든 항목을 확인할 수 있습니다.

    URL Advanced URLs

    메뉴를 선택하세요

    왼쪽 화면의 파란색 메뉴 글자를 누르면 해당 고급 페이지의 용도와 운영 시 확인 포인트를 볼 수 있습니다.

    무엇을 확인하나요?

    상태 확인과 장애 분석이 목적입니다. 변경 기능이 있는 화면은 운영 영향도를 먼저 확인합니다.

    운영 예시

    Access Log, DNS, Policy처럼 확인하려는 기능의 이름을 화면에서 직접 선택합니다.

    주의 · Advanced URL 중 일부는 지원 엔지니어용 진단 화면입니다. 기능을 모르는 상태에서 값을 변경하지 마세요.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 메뉴와 항목을 선택하세요.

    REPORT Traffic Details

    항목을 선택하세요

    왼쪽 화면의 메뉴, 탭, 그래프 또는 표 제목을 누르면 SGOS 로그 필드 정의에 맞춘 항목 설명을 확인할 수 있습니다.

    무엇을 확인하나요?

    조회 기간과 포함 조건을 먼저 확인한 뒤 Client Bytes, Server Bytes, Bypassed Bytes와 Savings를 비교합니다.

    운영 예시

    대역폭 증가 시 Traffic Rate에서 발생 시점을 찾고 Proxy Services 표에서 실제 증가한 서비스를 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 메뉴와 항목을 선택하세요.

    REPORT Traffic Details · Proxies

    항목을 선택하세요

    왼쪽 화면의 메뉴, 탭, 그래프 또는 표 제목을 누르면 SGOS 로그 필드 정의에 맞춘 항목 설명을 확인할 수 있습니다.

    무엇을 확인하나요?

    프록시 유형별 Client Bytes, Server Bytes, Bypassed Bytes와 Savings를 비교합니다.

    운영 예시

    HTTP와 HTTPS Forward Proxy 중 어떤 프록시 유형에서 트래픽이 증가했는지 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 탭과 그래프를 선택하세요.

    PROTOCOLHTTP/HTTPS/FTP

    항목을 선택하세요

    탭이나 그래프 카드를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    Connections, Objects, Client Bytes와 Server Bytes의 기간별 변화를 비교합니다.

    운영 예시

    연결 수와 전송량이 동시에 증가한 시점을 찾아 Access Log와 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 탭과 그래프를 선택하세요.

    PROTOCOLSSL

    항목을 선택하세요

    탭, Protocol 조건, 그래프 또는 Statistics를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    선택한 SSL 처리 유형의 연결 수, 전송 바이트와 누적 통계를 확인합니다.

    운영 예시

    Unintercepted SSL 연결이 증가한 시점과 누적 Bytes를 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 탭과 그래프를 선택하세요.

    PROTOCOLMAPI

    항목을 선택하세요

    탭이나 그래프 카드를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    MAPI 연결과 클라이언트 읽기·쓰기 바이트의 기간별 변화를 확인합니다.

    운영 예시

    Exchange 관련 체감 지연 시간에 MAPI 연결 또는 쓰기량이 증가했는지 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 탭과 그래프를 선택하세요.

    PROTOCOLSOCKS

    항목을 선택하세요

    탭, 그래프 또는 Statistics 표를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    SOCKS 연결과 Client/Server Bytes, 요청 유형별 누적값을 확인합니다.

    운영 예시

    SOCKS 접속 실패 시 CONNECT·BIND 요청 수와 양방향 바이트를 함께 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 조건, 그래프와 표를 선택하세요.

    REPORTThreat Risk Details

    항목을 선택하세요

    왼쪽 화면의 조건, 그래프 또는 표 영역을 누르면 SGOS의 Threat Risk 관련 필드 정의를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    위험도별 Hits와 시간대별 변화, 위험도 구성 비율을 함께 확인합니다.

    운영 예시

    Medium-High 또는 High 위험도 요청이 발생한 시각을 찾아 Access Log와 정책을 교차 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 Provider, Group, Subgroup, 그래프와 표를 선택하세요.

    REPORTCategory Details

    항목을 선택하세요

    왼쪽 화면의 조건, 그래프 또는 표 영역을 누르면 Broadcom SGOS 7.3 공식 Category Details 문서를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    Provider와 기간을 확인하고 Group·Subgroup·Category별 Hits와 구성 비율을 비교합니다.

    운영 예시

    Hits가 급증한 날짜와 상위 Category를 찾은 뒤 Access Log 및 정책 처리 결과와 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 선택 인터페이스, 여섯 그래프와 하단 인터페이스 표를 선택하세요.

    REPORTInterface History

    항목을 선택하세요

    왼쪽 화면의 인터페이스, 그래프 또는 표 영역을 누르면 Broadcom SGOS 7.3 공식 Interface History 문서를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    선택한 물리 인터페이스 또는 VLAN의 송수신 바이트·패킷과 입출력 오류 추이를 확인합니다.

    운영 예시

    LAN 인터페이스 트래픽이 지속적으로 용량에 근접하면 경로 분산이나 다른 장비로의 부하 분산을 검토합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 Services 탭, 네 그래프와 서비스별 통계 표를 선택하세요.

    REPORTContent Analysis · Services

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Content Analysis 문서를 기준으로 개별 ICAP 서비스의 처리 상태와 통계를 설명합니다.

    무엇을 확인하나요?

    현재 처리 중 요청, 완료 결과, 연결 수와 ICAP 서버 송수신 바이트를 확인합니다.

    운영 예시

    Failed Requests가 증가한 서비스 행을 선택해 같은 시각의 완료 요청과 ICAP 연결 상태를 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 Service Groups 탭, 세 그래프와 그룹별 통계 표를 선택하세요.

    REPORTContent Analysis · Service Groups

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Content Analysis 문서를 기준으로 ICAP 서비스 그룹 단위의 처리 상태와 통계를 설명합니다.

    무엇을 확인하나요?

    서비스 그룹별 현재 요청, 완료 결과와 ICAP 서버 송수신 바이트를 확인합니다.

    운영 예시

    그룹을 선택해 Charts를 해당 그룹 기준으로 좁힌 뒤 개별 서비스 장애 여부를 추가 확인합니다.

    Log Name, Log Tail 설정과 하단 Statistics의 상태 영역을 선택하세요.

    REPORTAccess Logging

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Access Logging 문서를 기준으로 Log Tail과 Statistics를 설명합니다.

    무엇을 확인하나요?

    로그 이름과 갱신 조건을 확인하고 생성·업로드 상태를 점검합니다.

    운영 예시

    외부 로그 수집이 끊겼다면 Upload Client와 Last Upload Attempt를 확인합니다.

    갱신 간격, Show Log Tail과 Download Log를 선택하세요.

    REPORTEvent Logging

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Event Logging 문서를 기준으로 이벤트 로그 조회와 다운로드를 설명합니다.

    무엇을 확인하나요?

    최신 이벤트를 실시간으로 볼지 파일로 보존할지 선택합니다.

    운영 예시

    장애 직후 Log Tail을 확인하고 event.log를 내려받아 보존합니다.

    Filter를 누르면 필터 목록이 열린 전용 가이드 화면으로 이동합니다.

    REPORTSessions · Proxied Sessions

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Sessions 문서를 기준으로 프록시 세션 조회와 작업을 설명합니다.

    무엇을 확인하나요?

    필터와 상태를 선택하고 Show를 눌러 현재 또는 오류 세션을 조회합니다.

    운영 예시

    장기 세션을 찾고 Client, Server, Service와 Duration을 비교합니다.

    열린 목록의 각 필터 이름을 눌러 공식 정의와 사용 예시를 확인하세요.

    FILTERProxied Sessions 필터

    필터 항목을 선택하세요

    None부터 Service까지 열린 목록의 각 항목을 눌러 설명을 확인합니다.

    무엇을 확인하나요?

    조회 목적에 맞는 필터와 입력값을 선택한 뒤 Show를 누릅니다.

    운영 예시

    Client Address로 사용자 단말의 프록시 세션만 좁힙니다.

    Filter를 누르면 우회 연결 필터 목록이 열린 전용 가이드 화면으로 이동합니다.

    REPORTSessions · Bypassed Connections

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Sessions 문서를 기준으로 우회 연결 조회를 설명합니다.

    무엇을 확인하나요?

    필터를 선택한 뒤 Show를 눌러 우회 연결을 표시합니다.

    운영 예시

    특정 서버로 향하는 우회 연결을 조회해 정책과 서비스 구성을 확인합니다.

    열린 목록의 각 필터 이름을 눌러 공식 정의와 사용 예시를 확인하세요.

    FILTERBypassed Connections 필터

    필터 항목을 선택하세요

    None부터 Service까지 열린 목록의 각 항목을 눌러 설명을 확인합니다.

    무엇을 확인하나요?

    주소, 포트 또는 서비스 조건을 선택한 뒤 Show를 누릅니다.

    운영 예시

    Server Address로 특정 목적지의 우회 연결만 좁힙니다.

    General, Licensing, Status, Subscription 영역을 눌러 Broadcom 공식 정의와 점검 방법을 확인하세요.

    REPORTHealth Monitoring

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Health Monitoring 문서를 기준으로 현재 지표 상태를 설명합니다.

    무엇을 확인하나요?

    상단 Warning의 원인이 되는 지표를 찾고 Value와 State를 함께 확인합니다.

    운영 예시

    Health Check Status가 Warning이면 Health Checks 화면에서 실패 검사를 확인합니다.

    Current Time, Last Boot와 표의 각 열을 눌러 공식 정의와 장애 점검 방법을 확인하세요.

    REPORTHealth Checks

    항목을 선택하세요

    Broadcom SGOS 7.3 공식 Health Checks 문서를 기준으로 검사 상태와 상태 전환 이후 통계를 설명합니다.

    무엇을 확인하나요?

    State에서 실패 검사를 찾고 마지막 검사 시간·응답 시간과 전환 이후 통계를 확인합니다.

    운영 예시

    Check failed 행의 Details와 Events를 열어 대상 응답과 관련 이벤트를 교차 확인합니다.

    기능 이름에 마우스를 올리면 설명이 표시되고, 클릭하면 해당 설정 화면으로 이동합니다.

    CONFIGConfiguration

    설정 기능을 선택하세요

    ProxySG의 정책, 네트워크, 프록시 서비스, 콘텐츠 분석, TLS 인증서와 관리자 인증 구성을 기능별로 안내합니다.

    사용 시점

    기능이 필요한 운영 상황과 해결하려는 요구사항을 설명합니다.

    적용 모드

    Explicit·Transparent·Reverse Proxy 또는 프록시 모드와 무관한 기반 기능인지 구분합니다.

    운영 예시

    기능 이름에 마우스를 올려 실제 사용 사례와 함께 검토한 뒤 필요한 설정 화면으로 이동합니다.

    Broadcom 공식 참고

    Edge SWG 7.4 Documentation

    주의 · Configuration 변경은 실제 프록시 트래픽과 관리 접속에 즉시 영향을 줄 수 있습니다. 작업 전 백업과 롤백 절차를 준비하세요.

    정책 기본 동작, Coverage, 정책 파일과 VPM 항목을 눌러 설정 절차와 주의사항을 확인하세요.

    CONFIGPolicy Settings

    정책 항목을 선택하세요

    일치하는 규칙이 없을 때의 기본 처리, 정책 적중 확인, 정책 파일 관리와 Visual Policy Manager 실행을 안내합니다.

    ADMINService Information · Snapshots · Edit

    스냅샷 작업 항목을 선택하세요

    스냅샷 작업의 실행 여부, 대상 페이지, 주기, 총 촬영 횟수, 보관 개수를 편집합니다.

    설정 방법

    대상과 주기를 정하고 보관 개수를 디스크 여유에 맞춘 뒤 Apply, 목록에서 Save합니다.

    운영 예시

    sysinfo_stats는 60분 주기·168개 보관으로 최근 7일 추이를 유지합니다.

    Capture 영역의 항목을 눌러 패킷 캡처 방법을 확인하세요.

    ADMINService Information · Packet Capture

    Packet Capture 항목을 선택하세요

    방향·인터페이스·BPF 필터로 장비를 지나는 패킷을 캡처하고 pcap으로 내려받습니다.

    설정 방법

    대상 IP·포트로 필터를 좁히고 Start Capture로 시작해 문제를 재현한 뒤 중지하고 Download합니다.

    운영 예시

    SSL 핸드셰이크 실패 분석 시 Filter에 "host 10.1.1.20 and port 443"을 넣고 Both로 캡처합니다.
