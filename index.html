    DASH Dashboard

    확인할 항목을 선택하세요

    왼쪽 화면의 항목을 누르면 Broadcom SGOS 7.3 공식 문서의 로그 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    상단 메뉴부터 시스템 사용량, 사용자 수, 트래픽 현황까지 차례로 살펴볼 수 있습니다.

    운영 예시

    CPU 사용률이 평소보다 높다면 시간 범위를 넓혀 일시적인 증가인지 지속적인 과부하인지 먼저 구분합니다.

    메뉴 글자 위에 마우스를 올리면 클릭 영역이 표시됩니다. 아래로 스크롤해 모든 항목을 확인할 수 있습니다.

    URL Advanced URLs

    메뉴를 선택하세요

    왼쪽 화면의 파란색 메뉴 글자를 누르면 해당 고급 페이지의 용도와 운영 시 확인 포인트를 볼 수 있습니다.

    무엇을 확인하나요?

    상태 확인과 장애 분석이 목적입니다. 변경 기능이 있는 화면은 운영 영향도를 먼저 확인합니다.

    운영 예시

    Access Log, DNS, Policy처럼 확인하려는 기능의 이름을 화면에서 직접 선택합니다.

    주의 · Advanced URL 중 일부는 지원 엔지니어용 진단 화면입니다. 기능을 모르는 상태에서 값을 변경하지 마세요.

    REPORT Traffic Details

    항목을 선택하세요

    무엇을 확인하나요?

    조회 기간과 포함 조건을 먼저 확인한 뒤 Client Bytes, Server Bytes, Bypassed Bytes와 Savings를 비교합니다.

    운영 예시

    대역폭 증가 시 Traffic Rate에서 발생 시점을 찾고 Proxy Services 표에서 실제 증가한 서비스를 확인합니다.

    무엇을 확인하나요?

    프록시 유형별 Client Bytes, Server Bytes, Bypassed Bytes와 Savings를 비교합니다.

    운영 예시

    PROTOCOLHTTP/HTTPS/FTP

    항목을 선택하세요

    무엇을 확인하나요?

    Connections, Objects, Client Bytes와 Server Bytes의 기간별 변화를 비교합니다.

    운영 예시

    연결 수와 전송량이 동시에 증가한 시점을 찾아 Access Log와 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 탭과 그래프를 선택하세요.

    PROTOCOLSSL

    항목을 선택하세요

    무엇을 확인하나요?

    PROTOCOLMAPI

    항목을 선택하세요

    탭이나 그래프 카드를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    PROTOCOLSOCKS

    항목을 선택하세요

    탭, 그래프 또는 Statistics 표를 누르면 공식 필드 정의와 화면 문맥을 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    SOCKS 연결과 Client/Server Bytes, 요청 유형별 누적값을 확인합니다.

    운영 예시

    SOCKS 접속 실패 시 CONNECT·BIND 요청 수와 양방향 바이트를 함께 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 조건, 그래프와 표를 선택하세요.

    REPORTThreat Risk Details

    항목을 선택하세요

    왼쪽 화면의 조건, 그래프 또는 표 영역을 누르면 SGOS의 Threat Risk 관련 필드 정의를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    위험도별 Hits와 시간대별 변화, 위험도 구성 비율을 함께 확인합니다.

    운영 예시

    Medium-High 또는 High 위험도 요청이 발생한 시각을 찾아 Access Log와 정책을 교차 확인합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 Provider, Group, Subgroup, 그래프와 표를 선택하세요.

    REPORTCategory Details

    항목을 선택하세요

    왼쪽 화면의 조건, 그래프 또는 표 영역을 누르면 Broadcom SGOS 7.3 공식 Category Details 문서를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    Provider와 기간을 확인하고 Group·Subgroup·Category별 Hits와 구성 비율을 비교합니다.

    운영 예시

    Hits가 급증한 날짜와 상위 Category를 찾은 뒤 Access Log 및 정책 처리 결과와 비교합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 선택 인터페이스, 여섯 그래프와 하단 인터페이스 표를 선택하세요.

    REPORTInterface History

    항목을 선택하세요

    왼쪽 화면의 인터페이스, 그래프 또는 표 영역을 누르면 Broadcom SGOS 7.3 공식 Interface History 문서를 기준으로 정리한 설명이 표시됩니다.

    무엇을 확인하나요?

    선택한 물리 인터페이스 또는 VLAN의 송수신 바이트·패킷과 입출력 오류 추이를 확인합니다.

    운영 예시

    LAN 인터페이스 트래픽이 지속적으로 용량에 근접하면 경로 분산이나 다른 장비로의 부하 분산을 검토합니다.

    한 장으로 연결된 전체 화면을 아래로 스크롤하면서 Services 탭, 네 그래프와 서비스별 통계 표를 선택하세요.

    무엇을 확인하나요?
